# Changelog

## 0.2.0 - Development
- Added data-driven pose presets.
- Added runtime pose executor with Montage and Animation Sequence support.
- Added pose commands by ID for Blueprint/UI usage.
- Added photo-subject selection.
- Added subject look-at-camera command.
- Added Selfie camera mode with socket anchoring, orbit, distance and smoothing controls.
- Added settings for selfie behavior and subject-rotation restore.
- Added architecture and roadmap documentation.

## 0.1.0
- Initial runtime Photo Mode foundation.
- Free camera, pause/HUD state handling, FOV and screenshot API.
